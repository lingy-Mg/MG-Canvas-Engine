# 图片和独立文字：精确属性

- 图片：X/Y、W/H、旋转角度以对象中心为轴。默认锁定**当前**宽高比例，最后修改的 W 或 H 为主；可关闭以自由拉伸。恢复原始比例则按原始图片像素尺寸计算，默认保持当前宽度，点「应用变换」后连同其他输入一起保存。比例锁状态保存在项目内，也参与撤销/重做。纯图片不提供替换像素的填充色。
- 文字：一组属性提供 X/Y、W/H、旋转、字号、文字颜色、对齐。「随文字」按内容自动计算高度；切换到「固定高度」后才能输入 H。文字过长时只在画布内裁切，原文完整保留，双击仍可全文编辑和用输入法输入。高度、字号、方向等一起应用，可一次撤销。
- 两种对象的 X/Y 都是旋转前矩形的左上角坐标。新版本可以读未记录模式的旧文件（文字自动高，图片启用比例锁）；项目包含新字段时不保证用严格校验的旧预览读取。
