# 画布操作

## 画布、选区与图层

打开或刷新画板时，视图会居中显示全部可见内容，避开浮动工具栏。空板从 100% 的默认视角开始。随时点击左上角「回到内容」，或在画布上按 `0`，都可以重新查看整板。在窄屏上，这个操作也会收起遮住画布的图层面板。对象相距很远时，整板适配可以低于 5%，再点放大即可从这个倍率逐步看近。

底部的导航工具、创作工具和撤销重做各有一组浮动按钮。当前工具带实色高亮，悬停或键盘聚焦可查看名称，快捷键在按钮右下角。窗口较窄时，「创作工具」集中显示可用工具，选择、平移、撤销和重做留在底栏。用 Enter 打开创作工具后可按 Tab 选择工具，按 Esc 返回入口。

在顶栏点「浅色」「深色」或「跟随系统」可切换工作区外观。紧凑窗口在画布右上角用「画布性能」打开帧率信息和设置。右键点空白处可在该位置添加流程节点或文字，也可全选可见对象、查看整板。流程连线的箭尖贴合端口，深色画布上的低对比度连线以同色系的较亮色调显示。

拖框时，选框左上角实时显示「已选 N 个元素」。松手后可按住 Shift 点选来增减元素。整张脑图计一个元素，局部框选按选中的主题计数。

鼠标指向对象时，青色轮廓沿节点外形、路径或笔迹显示。重叠处跟随点击命中顺序，流程组在组外整体高亮，在组内单独高亮成员。

画布元素新增时渐显，流程整理时节点与绑定连线一起移动，删除时连线随元素收回。系统开启「减少动态效果」时，画布直接显示编辑结果。

画布铺满窗口。图片浮栏可锁定比例、恢复原始比例或开关外阴影。顶栏「图层」可按名称查找、锁定或显示对象。次级工具栏可横向滚动，按 Tab 也可到达屏外的操作。窄窗中图层和格式栏分开排布，格式栏两端的箭头可翻看整排控件。短窗中的完整属性从画布上方展开，可在面板内滚动；按 Esc 返回打开它的按钮。界面、编辑框、画布文字和 PNG 导出共用系统与中文字体回退。

在图层面板的搜索框输入中文或英文，可跨页找到对象。点击结果沿用画布选区，重名按原图层顺序分别列出。清空可返回列表，打开另一张画板会重置搜索。 [241 层例板](fixtures/M5AF-Layer-Search.mgcanvas)

选中一张脑图后，图层面板会显示主题树。输入名称可找到当前脑图中已折叠的主题，点结果即可选中并定位。点图层列表中的脑图行可返回整图选择。从已选主题按 Tab 新建子主题，Enter 新建同级，F2 改名。 [练习例板](fixtures/M5AI-Topic-Tree.mgcanvas)

点击左栏「隐藏」可临时隐藏所选图层。隐藏行仍可搜索，点击该行可恢复。「全显」恢复全部。只隐藏某个流程组成员时，在该行按 Shift+F10 选「隐藏此层」。重开画板后各层重新显示。

选中对象或流程组，在图层面板标题旁点「锁定」，可防止本次编辑中误拖、改样式、调层、删除或剪切。锁层仍可选择和复制，点「解锁」恢复编辑。锁定仅限本次打开，重开画板会清除。 [混排例板](fixtures/M5AG-Layer-Locks.mgcanvas)

在图层面板点击或用 Enter、空格激活图层结果后，按 Ctrl+A 或 Cmd+A 即可选中整板可见对象。焦点和当前搜索页保留。搜索框和文字编辑区继续使用原生全选。

开发版以一个世界单位为对象位置的最小编辑步长。属性栏的 X、Y 接受整数，宽、高接受正整数。拖拽时按最近的整数落点预览和提交，文字自动高度向上取整以容纳整行。曲线控制点与旧工程沿用既有网格规则。新手写笔迹的对象位置仍按整数编辑，笔尖轨迹则保留小数坐标和设备压力，放大和重开后都能重现。

点画布右上角「吸附」，拖动单个元素或整个选区时，左边、中心线、右边可以互相贴齐，上下方向同理。开发预览用粉色虚线在对象之间提示对齐位置。把元素放到同一行或同一列的两个元素之间，可以平分空隙。接到任一端，可以沿用已有间距。两段青绿色标尺分别标出相等的空隙，空间够时各自显示数值。左上角同时显示实际对齐位置和间距。首次使用时吸附关闭，工作区会记住开关。普通移动开始后按住 Alt / Option 可临时暂停吸附。 [双节点对齐例板](fixtures/M5V-Drag-Alignment.mgcanvas)

按住 Alt（macOS 上的 Option）再从元素上拖动，会留下原件并拖出副本。已有多选时，从选区中任一元素起拖即可复制整个选区。副本沿用当前吸附设置。松开鼠标放置并选中新副本，按 Esc 放弃，放置后可一步撤销。

单选矩形、菱形、三角形或图片，拖上边中央短线末端的圆柄可绕中心旋转。四角方柄用于缩放。按住 Shift 吸附到画板坐标系每 15° 的角度，松开 Shift 恢复自由旋转。松手提交一次，Esc 取消。

按住 Shift 选中多个对象，在「整体位移」输入 ΔX、ΔY 即可预览相对移动。留空的轴保持原位，正值向右或向下。按 Enter 或点「应用」提交，一步撤销；按 Esc 或点「取消」恢复。共同外观可以与位移一同应用。

## 文字、便签、表格与图片

点底部「文档」「便签」或按 T 选文字工具，移入画布就能看见放置预览。单击放下并输入，放置前按 Esc 或切换工具可取消。新建 T 文本框的书写宽度为 360 个画布单位，Enter 换行，长段落自动折行，也可拖动左右边缘调宽。

Markdown 文档支持「导入 .md」和拖入文件。单击正文可在原排版上修改标题、粗体、列表、链接、引用和代码块，「Markdown 源文」可编辑全文。便签使用多行纯文本，悬浮栏可改字号、背景色、加粗和对齐。空文档和空便签会显示输入提示，点空白或其他工具提交编辑。

点底部「表格」，把指针移入画布即可预览 2 × 2 网格。单击按虚影位置放置，按 Esc 或切换工具可取消放置。点单元格后可直接输入，双击或按 F2 可修改原文。Tab 换格，Shift 点选可连选矩形区域。右侧加号增列，底部加号增行。左侧和上方的短柄可选择、插入或删除当前行列。拖动一行的下边线可改行高，拖动一列的右边线可改列宽，最后一行和一列也一样。拖动表体可移动整表，拖动四角可按各行列原有比例调整整表大小。

表格上方的格式栏可调整整表或所选单元格的文字。常用字号和字色可以直接点选。点左上角手柄或在选区按 Esc 可选中整表，再改样式时，新增行列也会沿用这些设置。单元格可与电子表格互相复制粘贴。含表格的工程使用 v6，首次本地保存时另建表格副本。

选中对象后，浮栏中的点选、改色和合法数值会立即更新画布并触发自动保存。同一控件内连续输入或拖动一次，可用 Ctrl+Z 或 Cmd+Z 一步撤销。改另一个属性会开始新的撤销步骤。输入未完成时，画布保留上一个合法值。清空脑图主题的可选宽度或描边粗细并移出焦点，可恢复继承值。文档、便签和表格也支持即时调整。选中单元格范围时，表格样式只作用于该范围。

选中独立文字，可在上方格式栏调整字色、背景、字体、字号、粗斜体和对齐。字体菜单用「中文 Ag 09」预览每种字体。在「变换」中输入精确位置、尺寸、角度或改变文字框高度方式。选中流程节点或形状后，可分别设置填充和边框色。「无填充」保留边框。便签浮栏直接提供浅黄、薄荷、天蓝和粉红四种纸色，以及 16、20、24 三档字号。当前字号可以直接输入。普通文字和文档也可在一级浮栏直接点选常用字号、字色与底色。文档浮栏通过标题和列表修改当前段落，通过粗体、斜体和链接编辑所选文字。文档的字号、字色和底色作用于整篇文档，「外观」可选择更多样式。按 Alt+F10 可进入工具栏，再用 Tab 切换控件。

默认文字随文字框底色或画布主题选择实心字色。显式设色随工程保存。衬线与无衬线各有中西文字体回退，换设备打开时仍保留所选字体。

单选独立文字，在属性栏输入字号、改行宽或调整颜色与对齐，即可在画布上看到排版和选框。改字号会同步更新行高和选框。

单选独立文字框，拖左边或右边的短柄即可改行宽。对侧上角固定，旋转后的文字沿自身横轴重排。高度设为「随文字」时向下增减行数，「固定高度」时保留原框并裁切溢出行。松手应用，Esc 取消，双击框内仍可编辑文字。 [多语言与旋转文字例板](fixtures/M5W-Text-Width.mgcanvas)

窄文字框会给中文括号、逗号留合适的断点，连写表情和组合重音保持完整。脑图的布局、点选和绘制共用同一组行，省略的标题仍可原位查看全文。在例板中把「审批（复核）」的右边拖到宽 48，能对照预览和松手后的三行文字。 [排版例板](fixtures/M5Y-Text-Layout.mgcanvas)

文件导入及粘贴的图片沿完整矩形显示轻柔外阴影，包括透明 PNG 的留白外沿。阴影随画布深浅主题调整。

选中图片，在浮栏「变换」中改坐标、宽高或角度时，图片和选框会随输入更新。保持当前比例时可用宽或高驱动，恢复原始比例时按嵌入图片的像素尺寸计算。 [图片例板](fixtures/Meeting-Room-Mobile-QA.mgcanvas)

图片缓存已满时，平移到新区域会释放屏外预览，让新进入视口的图片显示。多个实例共用同一张位图。例板可用于对照跨区域平移和同屏图片超出预览预算两种情况。 [图片例板](fixtures/M5AE-Image-Cache.mgcanvas)

## 流程节点与连线

从底部「图形」选择流程步骤、判断或三角形，移入画布即可看到对应虚影。单击按默认大小放置，按住拖动可自定尺寸。按 Esc 或切换工具可取消。

选中流程图的菱形判断节点，按 Tab 创建标为 Yes 的分支。再次选中同一菱形并按 Tab，会从对侧创建 No 分支。已有一个答案时会补齐另一支。

鼠标移到图形或便签的边中点时，虚线箭头会预览该方向最近的可连接对象，绿色圆环标出落点。点击或拖到目标上松手即可连接。从任一端口拖到空白处，松手后可以就地选择「流程步骤」或「判断／选择」。节点和连线可一步撤销。选择「仅保留连线」、按 Esc 或点菜单外会留下自由端点。拖动已有连线的端点可以重新绑定，拖到空白会分离该端。触屏在「连线」工具中也可依次点起点和目标，第二次点空白会创建一个相连的流程框。

新建流程连线默认使用曲线，Tab 创建的后续步骤和 Yes/No 分支也沿端口方向接入。单选连线，可在上方工具栏直接点「曲线」或「折线」。切换保留端口、箭头、标签和手工拐点，打开旧工程时沿用其中保存的走线。

选中连线后，方形控制点代表手动拐点。点中一个方块后按 Delete，或右键选「删除此拐点」，即可单独移除它。拖动中按 Esc 可恢复位置。删掉最后一个手动点后，连线沿当前路由重新走线，每次删除均可独立撤销。

删除流程节点时，走线完全笔直且创建后一直未编辑的连线也会一起删除。判断分支自动带上的 Yes 或 No 可以随线删除。走线有弯、手动改过端点、拐点、标签或样式的连线会保留，并在原端口处解绑。多选删除使用同一规则，一步撤销可恢复所有绑定。旧工程缺少连线编辑记录时，继续保留连线。

选中流程连线后，可直接修改描边、粗细、箭头、走线、手动拐点坐标和标签。用颜色文字框直接输入 `#000000`，即可把透明色或命名色明确改为黑色。独立文字、脑图主题、路径和笔迹也支持手输颜色。 [可导入例板](fixtures/M5AA-Connector-Colors.mgcanvas)

单选流程矩形、菱形或三角形，在右侧输入宽、高、角度、填色或边线即可生效，矩形还可改圆角。线端随节点变化，手工拐点保持原位。 [可导入例板](fixtures/M5Z-Shape-Properties.mgcanvas)

选中一个流程节点，将指针移到浮栏的「排列后续节点」即可预览。起点固定，沿出线连接的后续步骤按层对齐。单击应用，按 Esc 取消。触屏可点一次预览，再点一次应用。手动折点保留原位，整次排列可一步撤销。

连续分叉时，较长的后续路径会尽量沿主轴延伸，侧支按原有次序分行。自动端口随流向调整。手动指定的端口、判断标签、绑定和折点都保留。旧工程中未记录来源的端口沿用原绑定。

选中相连的流程节点，在画布或图层行的右键菜单中点「按连接关系整理所选流程」。键盘可按 Shift+F10、End、Enter。节点按流向分列，手工拐点固定在原世界坐标。一次整理可一步撤销。

在一张画板上，按 Shift 点选至少两个流程节点，从右键或属性栏选「创建流程组」，也可按 Ctrl / ⌘ + G。点组内任一节点或内部连接线可选中整组并一起拖动。双击成员或按 Enter 进入组内编辑，Esc 回到整组。含组项目首次本地保存会另建分组副本。 [双流程图例板](fixtures/M5X-Flow-Groups.mgcanvas)

## 思维导图

在开发预览中，选中流程节点或脑图主题后，直接输入可替换文字，再点一次可原位编辑。点空白、其他元素或工具栏会提交文字并执行这次点击，Esc 取消本次输入。框选脑图时只高亮命中的主题。拖动根节点可移动整图。一级分支按落点换侧或调整上下顺序，更深的分支拖到节点中部可改挂父节点，拖到上下缘或行间可排序，后代随分支一起移动。

按 Tab 添加脑图子主题时，可以立刻输入。新主题从父节点展开，相邻主题和连线一起移动。删除分支时，余下主题收拢，撤销可以从动画当前的位置恢复。系统开启「减少动态效果」后会直接显示最终布局。

单击脑图节点，可在节点上方的工具栏改属性。根节点可调整整图间距、大小、排列、皮肤、分支色板和原点，也可单独设置自身外观。节点文字默认自动撑宽，Ctrl+Enter 可换行，设置固定宽度后会自动折行。宽度、字色、填充和描边可分别恢复默认，或用「继承脑图样式」一次恢复。分支操作支持排序、折叠、展开和删除。以根为第 0 级，从第 3 级起节点更靠近父节点，可调整文字和下划线颜色。底线与前后分支平滑衔接，自动字色随背景切换。

点根节点可设置整张脑图的间距、大小、排列方式、皮肤和分支色板，也可在「整张脑图位置」调整 X、Y。点子节点可单独调整该主题的宽度、填色、文字和描边。

选中脑图里的具体主题，在「此主题外观」中改宽度或颜色，画布上的文字、枝线及选框会跟随输入。连续调整同一项可一步撤销。「继承脑图样式」恢复该主题的默认外观。

## 手写与矢量路径

在开发预览中点底栏「手写」或按 P，上方可切换普通笔、荧光笔、整笔橡皮、粗细和颜色。按住鼠标中键即可平移，松开继续书写。书写途中平移会保留已写笔段，跳到新的落点会另起一段，整次书写可以一步撤销。鼠标、无压感笔和普通触屏整笔使用所选线宽。压感笔和支持压力的触屏按设备读数改变粗细。打开「手指书写」即可用手指记笔记。 [手写与笔压](Ink.md)

单选一条已完成的笔迹，在「所选笔迹」中改 X 或 Y，首落笔点、笔迹和选框会一起移动。位置、笔宽、颜色、旋转增量及等比缩放都可直接调整。只改位置时保留全部原始相对采样和压力。

单选一条已完成的笔迹，在「所选笔迹」中改基础笔宽或颜色，画布上的笔迹和选框会一起更新。下一笔仍使用画笔工具的设置。

选择「路径」后逐点放置顶点。按 Enter 或点「完成开放路径」结束折线。至少三个顶点时，点回起点或点「闭合路径」可形成多边形。普通选择可移动整条路径，在属性面板可改描边、闭合填色或点「编辑顶点」拖动一个顶点。路径项目使用独立本地副本，浏览器无法提供所需存储时可导出完整项目。 [路径、图片与笔迹夹具](fixtures/M5R-Vector-Paths.mgcanvas)

选中一条路径，点「编辑顶点」再点「插入顶点」，在线上点一下即可加点。新点会落在原轮廓上。用键盘可按 I 或 Insert 进入插点，再按 Enter 在选中段的参数中点加点。编辑中可直接用 Ctrl/Cmd+Z 撤销，用 Ctrl/Cmd+Shift+Z 重做，Windows 也可用 Ctrl+Y。 [插点和跨网格样例](fixtures/M5T-Insert-Vertices.mgcanvas)

要弯曲一段线，选中路径并点「编辑顶点」，再点线段或输入段号，点「转为曲线」。拖圆点调整弧度，拖方点移动顶点。闭合路径的最后一段连回起点。重合的点可用「起点柄」「终点柄」或「顶点」指定。含曲线的项目首次保存时会另建 v4 副本。 [曲线混排样例](fixtures/M5S-Cubic-Paths.mgcanvas)

单选已完成的矢量路径，在「整条路径变换」里输入 X、Y，主体、选框和命中区域一起移动。旋转增量和等比缩放按开始调节时的路径计算。只改坐标会保留原顶点和控制柄。

单选路径后，拖顶部圆柄旋转，拖任一角柄以轮廓中心等比缩放，描边宽度固定。右侧「整条路径变换」按输入的旋转增量或缩放百分比即时变换路径。顶点编辑仍单独进入。 [曲线与细线样例](fixtures/M5U-Path-Transform.mgcanvas)

单选一条已完成的矢量路径，在浮栏「路径样式」改描边宽度、颜色，或切换闭合填充，即可看到曲线和选框的变化。

## 保存与重开

顶栏显示当前工程的标题。文件未提供标题时显示文件名，刷新或重开本地副本后仍可识别。缺少名称信息的旧现场显示原画板 ID，内置示例显示「会议室系统」。

在开发预览中，修改画板或文字草稿会触发自动保存，撤销和重做也会保存。每次保存同时记录当时的画布位置和缩放倍率。单独平移、缩放或回到内容不会触发写入，也不会推迟待保存的编辑。用同一浏览器重新打开同一地址，可恢复上次保存的内容、图片、文字草稿和光标。顶栏显示保存状态。若另一标签页已经保存了更新的现场，可先导出本页修改，再刷新查看。手动「保存」「重开」和工程文件导入导出仍可使用。
