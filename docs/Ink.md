# 手写笔迹

选择「手写」或在画布聚焦时按 P，即可用笔尖或鼠标左键书写。鼠标、无压感笔和普通触屏使用所选线宽，从落笔到收笔保持等宽。压感笔和支持压力的触屏按实际轻重改变线宽。默认手指平移画布，开启「手指书写」后可以单指记笔记。第二指落下会取消当前草稿并开始双指缩放。抬笔提交整笔，一次撤销即可移除。书写中按 Esc 取消当前笔，空闲时按 Esc 退出手写。

底栏上方的单行笔栏可直接选普通笔、荧光笔或笔迹橡皮。粗细示例和滑杆均可改宽度，八个预设色和多色色盘可改颜色。主栏显示当前笔型和所选色。两种笔在本次打开期间分别记住颜色和宽度，下一次落笔立即使用。荧光笔以 40% 不透明度绘制，同一笔折回时颜色均匀，另画一笔叠上去时颜色加深。

橡皮按屏幕像素设置直径，拖过可见、未锁定的笔迹即可擦除整笔，一次拖动只需一次撤销。抬手前按 Esc 可恢复正在擦的笔迹。在手写模式下，浏览器上报手写笔尾端橡皮信号时会临时启用橡皮，翻回笔尖即可接着用原来的笔写。[Pointer Events 的笔按钮约定](https://www.w3.org/TR/pointerevents3/#the-button-property)

笔迹是可独立选择、移动、复制、删除、改变图层顺序的矢量对象。选择后可直接改 X/Y、笔色、基础笔宽、旋转增量和等比缩放百分比。旋转和缩放均以第一落笔点为中心。缩放同时改变笔宽，各样本的压力保持原值。画笔工具自己的色宽设置用于下一笔。

鼠标始终使用所选线宽。每次笔尖或手指接触时，如果只收到 0.5、零值或无效读数，普通笔和荧光笔都按所选线宽绘制。收到有效的非默认正压力后，本笔使用设备读数，并恢复开头已收到的接触压力。原地按重、放轻也会留下变化。抬笔时沿用最后一次接触压力。[Pointer Events 的压力约定](https://www.w3.org/TR/pointerevents3/#dom-pointerevent-pressure)

手写工具接收原始指针更新、普通移动事件和合并采样。笔尖在下一可用绘制帧抵达最新位置。去抖仅修正笔尖后方的点，保留急转和折返。新轨迹保留小数坐标，等宽段使用一条圆角描边。预览、保存和重开使用同一条中心线，抬笔位置有变化时会补上最后一段。连续书写时隐藏选框，切回选择工具可看到刚写完的笔迹选框。[Pointer Events 的原始更新和合并采样](https://www.w3.org/TR/pointerevents3/#the-pointerrawupdate-event)

按住鼠标中键可立即平移画布，单独平移只改变视口。写到一半按中键，已写部分会跟随纸面移动。松开中键时，仍按住的笔尖会从当前世界坐标续写。落点相同会续接原笔，落点不同会留下分开的两段。先松书写键会保留平移前写下的部分。抬笔提交后，整次书写可一步撤销。[Pointer Events 的鼠标组合键约定](https://www.w3.org/TR/pointerevents3/#chorded-button-interactions)

命中、擦除、成品和 PNG 使用同一笔迹轮廓。深色模式为低对比度普通笔补一条视觉边缘。

## 项目和版本

工程沿用笔迹的 brushVersion 字段。新写的普通笔使用值 1，荧光笔使用值 2，无压感样本的压力固定为 0.5。旧版保存的压力值、荧光笔透明度和版本 3 模拟笔迹的渐细轮廓按原记录重现。三种笔迹可在同一工程内保存、重开及复制。

新录制的笔迹带有 `subpixel: true`。对象锚点保持整数，所有样本以该锚点为原点，首样本也会记录实际落点的小数偏移。旋转和等比缩放以实际落笔点为中心。含新笔迹的文件需要用支持该字段的版本打开。既有笔迹沿用原有精度和渲染方式。

没加入笔迹的旧版 v1 项目可直接打开，不因读取而迁移或改写。首次添加笔迹时，文档升到 v2，便携 .mgcanvas 外层版本不变，笔压、坐标、宽度和颜色与项目一起保存。旧版应用不认识 v2，请用支持手写的版本打开，不要以旧版重建覆盖。撤销首次添加笔迹可以回到旧 v1 快照；保存位置仍独立。

支持 IndexedDB 时，首次保存 v2 会询问是否**另建手写副本**，不会覆盖 v1 的当前副本或旧备用。可通过「手写副本」及原有恢复按钮打开各自快照。两者不会自动同步；损坏或未知版本的手写副本不会被当作空记录。手写副本也使用写前比对，可在另一页先保存导致冲突时保留本页未保存编辑。没有 IndexedDB 时保留旧版备用保存行为，但手写项目请直接导出 .mgcanvas，不会把 v2 写入旧版备用记录。

单笔最多 16,384 个不同位置/压力样本，超限取消该笔并提示分笔；项目笔迹样本总量上限 200,000。实时草稿不更新文档、不进撤销、不写项目；页面离开、捕获丢失、切换项目或工具中止草稿。Canvas2D 用相同可变半径几何绘制草稿/成品，提交后按轮廓命中，笔宽不靠位图分辨率。每帧处理草稿但不做每个笔尖样本的全板文档事务；长笔迹、设备延迟及密集画板表现仍须实际评估。

选中笔迹后可与当前剪贴板流程一起复制／粘贴：含笔迹的片段以 v2 保存压力样本；不含笔迹的片段仍用 v1。画板提交剪贴板写入后，若新的一笔已经开始或项目已切换，不再删除所选对象。画布仅处理系统传来的可信剪贴板事件，原位编辑器和属性输入仍保留自身的粘贴行为。
